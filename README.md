# Asansör Yanlış Kat Bakanlığı

**Resmi ad:** T.C. Hayali Ama Çok Ciddi Asansör Yanlış Kat Bakanlığı  
**Kısa ad:** AYKB  
**Slogan:** Hedef kat bir öneridir. Varış bir kaderdir.  
**Kuruluş:** 5 Ekim 2026, asansör 3 saniye erken kapandıktan sonra.

Bu depo, binadaki düğmeye basıp başka kata çıkan asansörlerin hukuki statüsünü düzenler. Yazılım çalışır. Mantık çalışmaz. Bu bir özelliktir, hata değildir. Hata bildirirseniz hata da yanlış kata gider.

## Neden var?

Çünkü birisi 4'e bastı, asansör 7'de durdu, içerideki herkes bunu normal karşıladı. Bakanlık bu sessizliği mevzuat saydı.

## Kurulum

```bash
python3 bakanlik.py
```

Bağımlılık yoktur. İnternet yoktur. Doğru kat da yoktur.

## Kullanım

```bash
python3 bakanlik.py --kat 4 --yolcu "Kayyum"
python3 bakanlik.py --kat 9 --yolcu "Kapı" --tutanak
```

Çıktı resmi tutanaktır. İtiraz mercii asansörün aynasıdır. Ayna da sizi yanlış katta gösterir.

## Teşkilat

| Birim | Görev | Başarı oranı |
| --- | --- | --- |
| Düğme İşleri | Bastığınız sayıyı duymazdan gelmek | %100 |
| Kapı Diplomasi | Tam binince kapanmak, tam inince açılmamak | %100 |
| Ayna İstihbarat | Sizi olduğunuzdan daha yorgun göstermek | sınıflandırılmış |
| Yanlış Kat Planlama | Varışı hedefle eşleştirmemek | anayasal |

## Yasal uyarı

Bu bakanlık gerçek bir kamu kurumu değildir. Gerçek asansöre bu kodu yüklemeyin. Gerçek asansör zaten bu kodu ezbere biliyor.

Gizli yazışma `protokol/ic-yazisma.txt` dosyasındadır. Açmayın. Açarsanız da yanlış dosyayı açmış olursunuz, böylece protokole uygun davranmış olursunuz.
